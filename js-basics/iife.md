# IIFE에 대해 설명해주세요.

**핵심키워드** : `IIFE`, `변수 오염`

## 즉시 실행 함수란?

`즉시 실행 함수(IIFE, Immediately Invoked Function Expression)`란 정의하자마자 바로 실행되는 함수를 의미합니다. 일반적으로 함수를 정의하면 나중에 호출해서 사용하는데, `IIFE`함수는 만들자마자 바로 `()`를 붙여서 즉시 실행합니다. `IIFE`는 함수 표현식이어야 하기 때문에 `()`로 감싸서 선언식이 함수 표현식임을 알려줍니다.

```js
// 일반적인 함수 정의
function sayHello() {
  console.log("Hello");
}

// IIFE
(function () {
  console.log("IIFE");
})();
```

---

`IIFE`를 사용하는 경우는 크게 두 가지가 있습니다.

첫번째로는 스코프를 분리하여 변수를 숨길 수 있습니다.
JS에서 `var`는 함수 스코프를 가지기 때문에, 전역에 변수들이 쌓이기 쉽습니다. 이 때, `IIFE`를 사용하면 해당 함수 내에서만 변수가 쌓이기 때문에 변수 오염을 막을 수 있습니다.

> `변수 오염(variable pollution)`
>
> 의도치 않게 기존 변수에 영향을 주거나, 같은 이름의 변수로 덮어써서 오류가 나는 상황을 의미합니다.
> 즉, 서로 다른 목적의 코드끼리 같은 이름의 변수를 쓰다가 충돌하는 경우, 변수 오염이 발생했다고 말할 수 있습니다.

두번째로는 웹 페이지가 로드될 때, 초기화 코드를 실행하고 싶을 때 사용합니다.

```js
(function () {
  console.log("초기화 시작!");
});
```
