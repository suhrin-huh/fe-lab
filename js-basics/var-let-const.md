# `var`, `const`, `let`의 차이에 대해 설명해주세요.

**핵심키워드** : `스코프`, `호이스팅`, `TDZ`

JavaScript에서 `var`, `const`, `let`은 모두 변수를 선언하는 키워드입니다. 이 세가지는 스코프, 호이스팅, 재할당 가능 여보, TDZ 관점에서 차이가 있습니다.

| 항목             | `var`                       | `let`            | `const`          |
| ---------------- | --------------------------- | ---------------- | ---------------- |
| 스코프           | 함수 스코프                 | 블록 스코프      | 블록 스코프      |
| 호이스팅         | O <br>(초기값: `undefined`) | O <br>(TDZ 발생) | O <br>(TDZ 발생) |
| 재선언           | 가능                        | 불가능           | 불가능           |
| 재할당           | 가능                        | 가능             | 불가능           |
| 초기화 필수 여부 | X                           | X                | O                |

> `스코프(scope)`
>
> 스코프는 변수, 함수, 객체 등이 유효한 범위를 의미하며, 선언된 변수를 어디에서 접근할 수 있는가를 결정짓는 규칙입니다.  
> 스코프는 `함수 스코프`와 `블록 스코프`로 나뉘는데요. `함수 스코프`는 함수 전체를 스코프로 가지는 경우입니다. 따라서 함수 내에 있으면 블록 내부에서 선언된 변수를 블록 밖에서도 접근이 가능합니다. `블록 스코프`는 `{}`로 감싸진 블록 내부를 스코프로 가지는 경우입니다. 따라서 블록 내부에 정의된 변수를 블록 밖에서 접근할 수 없습니다.

---

`var`는 함수 스코프를 가지며, 재선언과 재할당이 모두 가능합니다. 호이스팅시에 `undefined`로 초기화되므로, 선언 전에 접근하여도 에러가 발생하지 않고 `undefined`가 출력됩니다.

```js
console.log(a); // undefined
var a = 10;
```

`const`와 `let`의 경우 블록 스코프를 가지며, 같은 블록 내에서 재선언이 불가능합니다. `let`은 재할당이 가능하지만 `const`는 재할당이 불가능하므로 초기화가 필수입니다. 두 키워드 모드 호이스팅이 되지만 `TDZ`에 걸려 선언 이전에 접근할 경우 `ReferenceError`가 발생합니다.

```js
const c; // SyntaxError

console.log(b); //ReferenceError
let b = 20;
```

> `호이스팅(Hoisting)`
>
> 자바스크립트에서 코드 실행전에 변수, 함수 선언이 메모리에 먼저 저장되는 동작을 의미합니다. 선언이 코드의 맨 위로 끌어올려지는 것처럼 동작합니다.
>
> 자바스크립트는 3단계를 거쳐 변수를 생성합니다.
>
> 1. `선언(Declaration)`  
>    변수 이름을 등록하는 행위로 자바스크립트가 실행되기 전에 해당 변수를 이름만 알고 있는 상태로 만드는 것입니다.
>
> 2. `초기화(Initialization)`
>    변수에 기본값(`undefined`) 혹은 실제값을 할당힙니다.
>
> 3. 할당
>    이미 존재하는 변수(선언된 변수)에 값을 재지정합니다.
>
> `var`는 선언과 초기화가 함께 발생하지만, `let`과 `const`는 선언과 초기화가 동시에 일어나지 않고 TDZ에 빠지게 됩니다.
>
> `TDZ(Temporal Dead Zone)` > `TDZ`는 선언과 초기화가 이루어지기 전까지는 접근이 불가능한 구간을 의미합니다.
> JavaScript는 TDZ를 통해 초기화 이전에 접근하는 것을 금지합니다.
